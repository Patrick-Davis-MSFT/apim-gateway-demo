# Feature quickstart

1. Follow [container/deployment setup](../../docs/setup.md).
2. Run container-only validation and the live preflight.
3. Use the [presenter runbook](../../docs/runbook.md).
4. Open [walkthrough.ipynb](../../notebooks/walkthrough.ipynb).
5. Test skipping and repeating each module using its contract.

Existing model access and email verification are independent prerequisites for
their segments, not prerequisites for gateway demonstrations.
